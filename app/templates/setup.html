{# ---- Step 6: Newsletter folder in Outlook (optional, v0.3.0) ---- #}
6. Newsletter folder in Outlook (optional) click to expand

Reads a single named folder from your locally running Outlook desktop app — no passwords, no OAuth, no IT ticket. Set up an Outlook rule that files newsletters into a dedicated folder, then point the tool at that folder.

Path separator is /. Use the folder name exactly as Outlook shows it — German (Posteingang/…) or English (Inbox/…) depending on your Outlook language. Only this folder is read — never your whole inbox.

Not sure of the exact name? Run venv\Scripts\python.exe scripts\outlook_list_folders.py in a terminal to print every folder with its exact path.

Only fill in if Outlook has multiple accounts / shared mailboxes.

Preconditions: Outlook desktop app must be open and logged in when the collection runs. On first run Outlook may show a security popup asking to allow programmatic access — click Allow for 10 minutes. If the popup is blocked by Group Policy, contact IT.
